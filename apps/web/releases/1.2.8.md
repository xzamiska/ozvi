Balíky `@ozvi/sdk` a `@ozvi/widget` sú na npm a návod na prihlásenie funguje v ľubovoľnom jazyku.

### Pre všetkých
- Prihlásenie z vašej aplikácie: v Node.js stačí `npm i @ozvi/sdk`, pre Python a PHP je v dokumentácii (Widget → Sign people in) hotový úryvok bez knižnice. Token je bežný JWT podpísaný HMAC-SHA256.
- Widget ako balík: `npm i @ozvi/widget` (ESM, React a Vue s typmi).
- Nastavenie prihlásenia v boarde ukazuje aktuálny príklad a odkazuje na ďalšie jazyky.

### Pre správcov vlastných serverov
- Bez zmeny konfigurácie.
